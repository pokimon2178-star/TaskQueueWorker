# ⚙️ Task Worker Service

Надежный асинхронный микросервис на Go для фоновой обработки задач. Проект демонстрирует работу с пулом воркеров, очередями и базой данных SQLite для контроля состояний.

---

## 📁 Структура проекта

Код организован с разделением на слои для удобной поддержки и тестирования:

* **`main.go`** — Запуск: инициализация БД, сборка зависимостей и Graceful Shutdown сервера.
* **`task.go`** — Модели: описание структуры задачи и констант статусов (`PENDING`, `DONE` и др.).
* **`task_handler.go`** — API: обработка входящих HTTP-запросов на создание и проверку задач.
* **`task_repo.go`** — Данные: SQL-запросы для сохранения и обновления информации в SQLite.
* **`task_service.go`** — Логика: имитация работы (отправка писем, обработка фото) с задержками.
* **`manager.go`** — Воркеры: управление очередью в каналах и жизненным циклом горутин.
* **`manager_test.go`** — Тесты: проверка корректности обработки задач через мок-объекты.

---

## 🛠 Функционал

Сервис реализует ключевые паттерны параллельного программирования:

1. **Worker Pool**: Использование фиксированного числа горутин для эффективной обработки очереди.
2. **Task Persistence**: Сохранение прогресса в БД, чтобы не терять статус задач при перезагрузке.
3. **Smart Retries**: Автоматический повтор выполнения при временных сбоях (до 3 попыток).
4. **Context Control**: Управление отменой задач и таймаутами через стандартный пакет `context`.
5. **Graceful Stop**: Корректное завершение работы без обрыва активных задач по сигналу ОС.
